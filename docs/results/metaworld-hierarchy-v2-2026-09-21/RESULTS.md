## 费用口径

- Jev：435,903 input token × $0.042/M，输出 token 官方价按 $0/M，估算 $0.018308。
- GPT-6 Astra：316,469 input token × $10/M，加 8,812 output token × $50/M，估算 $3.605290。
- 这是按服务商返回的 usage 字段和官方公开单价估算；GPT 缓存命中未在日志中拆分，所以按未缓存标准价。不同供应商 token 不可直接当作等价计算量。

## 超时原因

补测前的两次 GPT-6 中断是 HTTP `ReadTimeout`：请求已经发出，但上游接口或网络链路没有在客户端等待窗口内返回。它不是输入格式错误；同一冻结 v2 runtime、同一 saved connection、同一任务种子后来能完成到官方成功，说明任务输入和控制链路可用。最终主结果只采用成功补测后的完整六局。

## 仍然失败的局

两模型都只剩 `push-v3-0` 步数耗尽。轨迹显示物体被推动过，但后段接触保持和重新对齐失败，最终没有进入官方成功阈值。这更像推物路径和恢复策略问题，不是完全没有理解目标。

## 范围

本实验是 Meta-World 3.1.1 / MuJoCo 3.3.0 的三任务开发子集：reach、push、pick-place，各 seed 0、1。输入是结构化特权状态，不是视觉 VLA；v2 同时改了状态表达、子目标提示和控制阶段，因此不能声称为纯子目标单因素消融。

实际返回模型：Jev `jev-1.13.0`；GPT-6 `gpt-6-astra-2026-09-03`。每局上限 200 步、40 个规划周期、80 次请求、600 秒，动作幅度 0.5，action repeat 5。
