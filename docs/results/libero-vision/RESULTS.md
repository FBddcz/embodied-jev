## 轨迹结论

**抽屉两组均在增加预算后成功。** 纯 GPT-6 为 456 步、609.8 秒；GPT-6 + Jev 为 314 步、319.7 秒，费用分别约 $2.15002 / $0.39400。该任务混合组费用少 81.7%、总耗时短 47.6%。

纯 GPT-6 微波炉在 459 步、839.7 秒完成；混合组在 1120 步、1200 秒后仍未完成，单独分析与重测中。离线复放末端轨迹最大偏差为 0。混合组门开度从 86.03° 降到最低 55.78°（第 162 步），最终为 61.11°；174/224 次局部动作中，末端移动超过 5 mm 而门角度变化不足 0.05°。

**Jev 的 1344 个运动轴选择均符合当前航点误差的方向与容差，夹爪也遵循规划要求。** 现有证据更指向高层航点、接触保持和进度判断，而非 Jev 选错轴方向。GPT 只看到当前图像与最近位移，程序仅用末端是否移动判断停滞；因此“手臂在动但门不动”没有可靠触发重新规划。这是诊断结论，不是已验证的修复效果。

## 对照范围

- 双相机 RGB-D 与本体反馈；不向模型提供物体真值或成功谓词。GPT-6 负责两组视觉规划，局部动作分别由 GPT-6 与 Jev 选择。
- libero_90 任务 0 / 33，初态 0、seed 0；配对初态、初始化后状态与模拟器版本一致。每局成功或运行满 1200 秒停止，无步数／请求上限；每局费用准入保护 $20。
- 实际返回模型：gpt-6-astra-2026-09-03、jev-1.13.0。延迟含网络等待；总耗时含初始化，1200 秒预算从初始化完成后计时。
- 费用按冻结协议单价估算：GPT-6 每百万输入／输出 token $10 / $50；Jev 为 $0.042 / $0。Jev 有输出 token 统计，但输出免费。中转账单可能不同。
- 若到时截断的请求未返回用量，费用显示 ≥ 已知小计，token 标为已报告部分；不把未知用量当作免费。
- 两个开发任务的系统对照，未训练 VLA，不是完整 LIBERO 评测。墙钟预算允许不同模式执行不同数量的动作。
